# 영어 해석 코치

2026년 9월 고1 학력평가 영어 **18~40번**을 위한 해석 연습 도구.

지문을 한국어로 해석해서 넣으면 채점받고, 틀린 이유가 다섯 갈래(어휘·구문·논리·지시어·범위)로
자동으로 쌓여서 약점이 보인다. 폰에서 쓰라고 만들었다.

```
문항 고르기 → 해석 타이핑 → 채점 → [결과][오류][분류][결정문장][다음] 5줄 → 기록·통계에 반영
```

---

## ⚠️ PDF와 지문은 절대 커밋하지 마라

이 레포는 **공개**다. 그리고 해설지에는 `무단 전재 및 재배포는 금지됩니다`(EBSi)가 박혀 있다.

- PDF는 `data/`에 두고, `data/`와 `*.pdf`는 `.gitignore`에 있다.
- 추출한 지문은 **브라우저 안에만** 저장된다(IndexedDB). 서버로 올라가지 않는다.
- 배포본도 마찬가지다. PDF는 각자 기기에서 읽고, 서버는 채점 한 건을 잠깐 거칠 뿐 저장하지 않는다.

커밋 전에 한 번 확인해라:

```bash
git status --short                 # data/ 나 .pdf 가 보이면 안 된다
git ls-files | grep -c '\.pdf$'    # 0 이어야 한다
```

시험지에서 아무 문장이나 하나 골라 레포 전체를 훑어보는 것도 좋다:

```bash
git grep -i "<시험지에서 복사한 영어 문장 한 토막>"   # 아무것도 안 나와야 한다
```

## 두 가지 모드

**Claude.ai 구독과 Anthropic API 키는 별개 결제다.** 키가 없어도 전부 쓸 수 있게 두 모드로 만들었다.

| | 복사 모드 (키 없음) | 자동 모드 (`ANTHROPIC_API_KEY` 있음) |
|---|---|---|
| 채점 | 프롬프트를 만들어 복사해 준다 → Claude 앱에 붙여넣기 → 돌아온 5줄을 도로 붙여넣기 | 버튼 한 번, 결과가 바로 뜬다 |
| 채점 품질 | 같다 (같은 함수로 프롬프트를 만든다) | 같다 |
| 기록·통계·단어·통째로·정리 | 전부 동작 | 전부 동작 |

복사 모드도 프롬프트 안에 지문·정답·모범해석이 그대로 들어가므로 지어낼 여지가 없다.
키를 나중에 넣으면 코드 수정 없이 자동 모드로 바뀐다.

## 돌리기

```bash
npm install
cp .env.example .env        # 비워둬도 복사 모드로 돌아간다
npm start                   # http://localhost:3000
```

첫 실행 때 문제지·해설지 PDF 두 개를 올리면 된다. **순서는 상관없고**, 내용을 보고 알아서 가린다.
한 번 올리면 그 기기에 저장돼서 다시 안 올려도 된다.

`.env`:

```
ANTHROPIC_API_KEY=      # 있으면 자동 채점. console.anthropic.com 에서 발급
APP_PASSWORD=           # 배포할 거면 꼭 채워라. 로컬은 비워도 된다
PORT=3000
```

## 학습지 단어 시험

헤더의 **단어 시험**(`/quiz.html`)은 완전히 별개 기능이다. 지문 채점이 아니라, 단어·뜻이 줄줄이 있는
학습지를 올리면 클래스카드처럼 4지선다 문제를 즉석에서 만들어 준다.

- 한 줄에 단어 하나. `apple 사과`, `apple - 사과`, `apple: 사과`, 탭 구분, 번호·기호 접두 다 알아본다.
- 텍스트를 붙여넣거나 `.txt`/`PDF`로 올린다. PDF는 해석 코치와 같은 pdf.js 파이프라인으로 텍스트만 뽑는다.
- 읽은 항목을 표로 보여주고 확인한 뒤에 저장한다 — 잘못 읽혔으면 그 자리에서 바로 보인다.
- 시험은 **API 없이** 그 학습지 안에서 오답(distractor)을 뽑아 만든다. 한 회 최대 50문제,
  항목이 그보다 적으면 있는 만큼만 나온다(부풀리지 않는다).
- 방향은 단어→뜻 / 뜻→단어 / 섞어서 중 고른다.
- 채점 후 틀린 것만 모아 바로 다시 볼 수 있다. 학습지와 시험 기록은 해석 코치와 같은 방식으로
  이 기기(IndexedDB)에만 저장된다.

## 배포 (폰에서 쓰기)

**Render 무료 웹서비스**를 권한다. 평범한 Express 앱이라 로컬과 똑같이 돈다.

1. Render에서 New → Web Service, 이 레포 연결
2. Build `npm install`, Start `npm start`
3. Environment에 `APP_PASSWORD` (그리고 있으면 `ANTHROPIC_API_KEY`) 추가
4. 배포되면 폰 브라우저로 접속 → 로그인 → PDF 올리기

무료 티어는 15분 놀면 잠들어서 첫 접속이 30초쯤 걸린다. 공부하는 동안은 계속 깨어 있다.

> Vercel도 되지만 서버리스 함수 본문이 4.5MB로 막혀서, 나중에 PDF를 서버로 보내는 기능을 더하면
> 그때 터진다. Render가 속 편하다.

```bash
npm test                                                    # 36개. API 키 없이 돈다
npm run check-bank data/eng_1_mun.pdf data/eng_1_hsj.pdf    # 18~40 전수 점검
```

`check-bank`는 23문항 각각의 지문·선지·정답·모범해석이 제대로 뽑혔는지 본다.
**여기가 틀리면 채점이 전부 틀리므로** PDF를 바꿀 때마다 돌려라.

모델 ID, 캐시 위치, Opus 5가 거절하는 파라미터를 여기서 잡는다.

## 어떻게 만들어졌나

### 지문을 지어내지 못하게 하는 방법

이 도구의 첫 번째 요구사항은 "절대 기억이나 추측으로 지문 내용을 만들어내지 마라"였다.
프롬프트 문장 하나에 맡기지 않고 구조로 막았다.

1. **지문이 요청에 통째로 들어간다.** PDF를 업로드하지 않는다. 해당 문항의 지문·정답·해설지
   모범해석을 그대로 넣어 보낸다. 지어낼 여지가 없다.
2. **해설지에 없는 문항은 모델을 태우지 않는다.** 데이터에 없으면 코드가 바로 `해설지에 없음`만
   내놓는다. API 호출 0회.
3. **인용을 대조한다.** `[결정문장]`이 정말 그 지문에 있는 문장인지 코드가 확인하고, 아니면
   `⚠ 지문에 없는 문장` 배지를 붙인다. 빈칸을 채워 인용하는 경우까지 감안해 낱말 쌍 일치율로 본다.

부수 효과로 호출이 가벼워졌다. 50쪽 PDF를 매번 붙이는 대신 문항 하나치 2천 자 남짓만 보낸다.

### 통계를 모델에게 세게 하지 않는다

`정리` 명령은 모델을 부르지 않는다. 채점 결과를 정해진 포맷으로 파싱해 기기에 쌓아두고, 분류별
개수는 코드가 직접 센다. 모델이 대화 기억으로 세면 세션이 끊길 때 사라지고 수도 틀린다.
`단어`와 `통째로`도 해설지에 이미 있는 내용이라 부르지 않는다.

포맷이 깨진 응답은 원문 그대로 보여주되 기록에는 넣지 않는다. 통계가 오염되는 것보다 낫다.

### PDF 읽기

문제지는 2단, 해설지는 3단 조판이라 pdf.js가 주는 순서를 그대로 믿으면 단이 섞인다.
그래서 좌표로 다시 조립한다.

- **단 나누기**: "이 세로 띠를 가로지르는 줄이 몇 개인가"를 세서 빈 띠를 찾는다.
  왼쪽 정렬점을 세는 방식은 안내문 들여쓰기를 단 경계로 착각한다.
- **띄어쓰기**: PDF가 흘려준 공백 문자가 아니라 글자 사이 간격으로 판정한다. 해설지는
  양끝맞춤이라 공백 문자를 믿으면 `생 겨 난 다` 처럼 깨진다.
- **줄 잇기**: 한글끼리 끊긴 줄은 붙이고(한글은 줄바꿈으로 낱말이 쪼개진다), 나머지는 띄운다.

### 알려진 한계

- **한국어 모범해석에 띄어쓰기가 간혹 빠진다.** PDF의 한국어 줄바꿈은 낱말 중간에서도 일어나는데
  공백 문자가 없어서 낱말 경계인지 구분할 신호가 없다. 낱말 중간에 공백을 잘못 넣는 것보다
  빠뜨리는 쪽이 낫다고 보고 그렇게 뒀다. 읽는 데 지장은 없다.
- **폰과 PC는 기록이 따로 논다.** IndexedDB라 기기마다 별개다. 설정 → 기록 옮기기로
  내보내고 불러와야 한다.
- **38·39번(삽입)의 `통째로`**: 주어진 문장은 따로 떼어 보여준다. 해설지 해석에서는 그 문장이
  끼워 넣어진 자리에 가 있어서 그냥 짝지으면 한 칸씩 밀린다.
- **다른 회차도 된다.** 은행 구조가 회차에 묶여 있지 않아서 11월 모고 PDF를 올려도 같은 방식으로
  읽는다. 다만 조판이 다르면 `check-bank`로 먼저 확인해라.
